ClipForge

ClipForge is a desktop application for macOS that turns long videos and livestreams into short, captioned, watermark-free clips. Speech recognition, highlight detection, reframing, subtitle rendering and encoding all run on the user's own computer. There are no accounts, no paid APIs, and no third-party processing of the footage.

What the app does

  • Normal video clipping — import an MP4/MOV/MKV/WebM file or a supported video URL, transcribe it locally with Whisper, rank the strongest moments and export ready-to-post shorts.
  • Recorded stream clipping — the same engine with facecam and gameplay layouts, automatic facecam detection and smart reframing.
  • Live stream clipping — capture an HLS or RTMP stream, analyse the rolling audio and speech, and cut clips while the broadcast is still live.

How it runs

The download is a small Python engine plus a local web interface served on 127.0.0.1. Everything — the database, your clips, the speech model — stays in a data/ folder on your machine. The only network traffic ClipForge performs on your behalf is fetching the video URL you ask it to clip, and uploading to a YouTube channel you explicitly connect.

YouTube uploads

ClipForge can upload finished clips straight to your own YouTube channel using Google's YouTube Data API. You connect a channel by signing in with Google and granting the youtube.upload and youtube.readonly scopes. The resulting OAuth tokens are stored only in ClipForge's local database on your computer; they are never sent anywhere else, and you can remove a channel at any time from the app's Settings page, which also revokes the token with Google.

ClipForge never uploads anything you did not explicitly post, and it never posts on a schedule. See the privacy policy for the full detail.

Requirements

  • macOS (Apple Silicon or Intel)
  • Python 3.10+ and Node.js 18+
  • ffprobe on the PATH
